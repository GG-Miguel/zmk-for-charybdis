# zmk-config for charybdis 
This library provides firmware specifically for the wireless hot-swap Charybdis customized by MiaoMiao, while also ensuring full compatibility with the official soldered version.

Keys are remapped in the browser using the [Keymap Editor](https://nickcoutsos.github.io/keymap-editor/).

## Design Objectives

### 1. Ergonomic QWERTY Base Layer
- Standard **QWERTY layout**
- **Home-row modifiers**
  - Tap = letter
  - Hold = modifier (GUI / Alt / Shift / Ctrl)
- Optimized hold-tap timing to reduce misfires
- Comfortable thumb usage for layer access

---

### 2. Dedicated Layers

#### 🔣 Symbol Layer
- Programming-focused symbols:
  - `() [] {} <>`
  - `= + - * /`
  - `& | ^ ~ ! ?`
- Punctuation and frequently used operators
- Designed for coding efficiency

#### 🖱 Mouse / Pointer Layer
- Trackball-optimized mouse controls
- Cursor movement
- Scroll (vertical and/or horizontal)
- Mouse buttons (left / right / middle)
- Optional precision / DPI modes

#### 📡 Bluetooth Layer
- Bluetooth profile switching
- Pairing / clearing profiles
- Designed for quick host switching
- Minimal risk of accidental activation

---

### 3. Charybdis-Specific Optimization
- Trackball behavior tuned for daily use
- Thumb clusters used for:
  - Layer access
  - Mouse interaction
- Layout designed around split ergonomics
- Wireless-friendly configuration
  - Right half as primary (central)
